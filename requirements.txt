# sentence-transformers depends on torch, and a plain `pip install torch`
# pulls the CUDA-enabled build — several GB of nvidia-* packages that this
# app, running on Streamlit Cloud's CPU-only free tier, never uses. The line
# below adds PyTorch's CPU-only wheel index; because those wheels carry a
# "+cpu" local version suffix, which PEP 440 sorts as *newer* than the
# plain version, pip picks the ~200MB CPU wheel over the ~3GB CUDA one
# without needing to pin an exact version. If a future deploy log shows it
# still grabbing the CUDA build, pin torch explicitly to the +cpu version
# shown in that log, e.g. torch==2.8.0+cpu.
--extra-index-url https://download.pytorch.org/whl/cpu
torch
