4. Deploy på Streamlit Cloud

Gå til share.streamlit.io → log ind med GitHub
Klik "New app" → vælg dit repo → app.py
Under "Advanced settings → Secrets", indsæt:

toml   GROQ_API_KEY = "din-nøgle-her"

Klik Deploy — du får en offentlig URL du kan dele med klienter


Det er det! Klienter kan nu:

Åbne linket i en browser (ingen login nødvendigt)
Stille spørgsmål på engelsk
Få svar med kildehenvisning til hvilke videoer svaret kommer fra


Eneste begrænsning: Streamlit Cloud gemmer ikke indeksering mellem restarts, 
så den bruger ~30 sek på at indeksere ved første load. Det sker automatisk 
i baggrunden mens siden åbner
